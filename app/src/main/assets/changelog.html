Changelog

1.0 — Arktos Mobile: first release

Rebrand & project

  • Rebranded from SmartCookieWeb to Arktos Mobile — new package, Arktos icon set in every density and flavor, neutral defaults replacing dead hosted services.
  • Engine-coupling audit groundwork for a possible future selectable-engine effort.
  • Known Android WebView platform limits documented honestly in LIMITATIONS.md.

Rust core

  • New Rust core (arktos-core via UniFFI): unified ad/malware/site-block/LAN request engine, one verdict per request.
  • Storage moved to a single Rust database (ArktosStore) replacing five separate databases.
  • Search suggestions, userscript parsing, download filename rules, bookmark import/export, reader mode and URL utilities run in Rust.
  • Multi-list adblock subscriptions with a desktop-style filter & rank list manager under Privacy settings.
  • Tranco + Majestic site-rank lists, consent-gated, powering site-rank features.
  • App-lock and parental passwords hashed with argon2id, upgrading legacy entries in place.
  • Store schema v3 adds userscript run-at/no-frames columns and GM_*Value persistence.

Fixes carried over from upstream SmartCookieWeb issues

  • Error pages use a stable base URL (#328); StartPage search moved off retired endpoints (#326).
  • AMOLED theme: the active tab is now distinguishable in the drawer (#298).
  • Option to trim protocol/www in the URL bar (#278); certificate dialog fits at max font scale (#277); text zoom up to 400% (#275).
  • 'Follow system' dark mode for browser theme and the dark-web addon (#251).
  • One-tap new tab in drawer mode (#299); option to swap tabs/bookmarks icons (#297).
  • Downloads verify integrity, retry truncated transfers, resolve real filenames instead of .bin, and warn when a page is served instead of a file (#270/#311/#303).
  • Error pages no longer overwrite the tab's real URL (#281); first tap after returning to the app navigates correctly (#309).
  • SSL warnings limited to one per page load (#296); links prefer installed apps over the store (#316); picture links no longer crash (#306).
  • App-lock prompt survives a mistyped password (#302); per-site JavaScript/cookie quick-toggles (#305).
  • Dedicated 'No internet connection' page when offline (#323); forced SafeSearch for parental controls (#327).
  • Translation rebuilt on a configurable LibreTranslate-compatible endpoint (#300).
  • WebView Safe Browsing channel disabled; reader-mode and proxy bypass leaks fixed.
  • Userscript engine rebuilt on document-start injection with a real GM bridge — @run-at/@exclude/@require honoured, GM_xmlhttpRequest and GM.* APIs implemented.

Interface

  • Error, block, start and incognito pages restyled to the Arktos desktop look — aurora wave, card layout, dark variants.
  • This changelog — readable in-app here and maintained in the repo root ChangeLog file.
  • Arktos light/dark brand themes in the picker; 'Follow system' resolves to them.
  • Site shield in the toolbar opens a per-site privacy panel; the padlock reflects the site's verdict.
  • Bookmark favicons resolve directly from each host — no third-party icon service.
  • Tabs drawer header offers close-all / close-others; closing the last tab leaves a fresh default tab instead of exiting.
  • 'Close browser' sits under Settings in the page menu; menu rows hide when no page can act on them.

Settings & stability

  • Every settings screen audited: dead toggles wired up or removed, validation added where bad input could persist (download path, manual proxy, custom search URL — https only).
  • Import/export rebuilt on the Storage Access Framework: typed settings round-trip, content-sniffed bookmark formats, working tab backup/restore.
  • Parental-control lockout fixed; all password fields now mask input.
  • Tab sessions restore in order, save-state failures are handled, and a corrupt session can't leave the browser with zero tabs.
  • RxJava 3 migration, targetSdk 35, deprecated news feed removed.

Security

  • Browser-wide app lock — PIN, password, or biometric unlock, with a configurable re-lock timer (immediately, 1/5/10 min, or custom).
  • Password-encrypted backup archives (PBKDF2 + AES-256-GCM) in Settings → Import/Export; restore needs the password.
  • Auto Backup no longer carries the browsing database in plaintext — history/bookmarks/downloads only leave the device via the encrypted archive.

Search suggestions

  • Provider list rebuilt: Baidu and Naver removed; Startpage and Qwant added — all providers are HTTPS.
  • New installs default to DuckDuckGo; choices for removed providers migrate to DuckDuckGo instead of switching to Google.
  • Qwant requests use the device locale (e.g. de_DE, pt_BR) instead of a hardcoded en_US.

Security (continued)

  • Mixed content blocked by default; Force HTTPS warns on cleartext navigations instead of silently upgrading.
  • Translation bridge reduced to a postMessage surface; the userscript GM bridge enforces @connect domains.
  • Incognito windows can't be screenshotted or previewed in recents; optional secure-window toggle for the whole app; dialogs hardened against tapjacking overlays.
  • Exported components and incoming intents audited; the panic trigger sits behind a privacy toggle; release builds shrink unused resources.
  • Warnings before executable or disguised downloads; internationalized domains display as punycode; optional referrer trimming on navigations.
  • CI checks dependency integrity, secrets and the manifest; the browsing database encrypts at rest; toolchains pinned for reproducible builds.
  • Navigations send Do Not Track and Global Privacy Control signals; POST forms no longer lose their body when privacy headers are enabled.

Two engines

  • The browser core sits behind a real engine seam — the WebView build ships as Arktos Light, a GeckoView build as Arktos (arm64).
  • GeckoView parity: navigation policy, SSL errors, tab state, prompts, downloads, storage/cookies, proxy/I2P and userscripts.

Incognito hardening

  • The incognito data partition is wiped when the session ends and on fresh start — cookies and logins can't carry between private sessions.
  • Panic clean covers the incognito profile; the private-tabs reminder stays off the lock screen; incognito typing doesn't feed keyboard learning.

Modernization

  • Deprecated APIs swept out: file picking, permissions and activity results use modern contracts; camera uploads use safe FileProvider URIs.
  • Dead code removed: old preference-activity wrappers, the reflection-based permissions framework, duplicate animators.
