A web browser with privacy on by default. Forked from SmartCookieWeb (Lightning Browser).

Features:
- Open source
- Modern UI
- Tracking and ad blocker
- Customizable
- Userscript support (Greasemonkey-style .user.js scripts)
- Proxy support: Orbot/Tor, I2P, or a manual HTTP proxy
